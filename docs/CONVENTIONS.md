# 五门专业课口径约定（docs/CONVENTIONS.md）

> 生成器以国内主流教材为准；国内外教材存在差异时，不悄悄改成某一种，而是在这里写清
> 当前实现采用的口径、原因与出处。每次修复都配 `src/algorithms/*Generators.test.js`
> 回归测试，确认修复前失败、修复后通过。

## 1. 磁盘扫描的两种折返方式

- **当前口径**：`scan()` 向当前方向移动到物理边界（`maxTrack`/`0`）后才折返，即使
  该方向最后一个请求之后没有更近的请求。
- **差异**：汤小丹《计算机操作系统》第四版的例题按最后一个请求处折返；Silberschatz
  体系里那是 **LOOK**（SCAN 到磁道端点，LOOK 见最后请求即回）。两种算法都会在教材里
  出现，名称不统一。
- **处理**：页面和生成器可选“走边界”的 SCAN 与在最后请求折返的 LOOK。磁道数 200 对应编号 0–199，默认使用边界扫描；汤小丹教材例题可切换到 LOOK。
- 出处：汤小丹等《计算机操作系统（第四版）》磁盘调度；Silberschatz *Operating System
  Concepts* SCAN/LOOK 定义。回归：`osGenerators.test.js`（边界扫描 280，LOOK 250）。

## 2. RR 在时间片边界，新到达进程先于被抢占进程入队

- **当前口径**：时间片到期的同一时刻，先 enqueue 此刻到达的进程，再把当前进程放回队尾。
- **差异**：有的教材先重排被抢占进程、再放入新到达者。两种都是合法 RR 约定。
- **处理**：生成器（`roundRobin.js`）与 Python 示例一致采用“先到达后抢占”，并以独立
  参考实现对拍锁定。
- 出处：汤小丹《计算机操作系统（第四版）》RR 章。

## 3. 银行家安全序列的遍历次序：一轮内不回退

- **安全序列不唯一**：只要能找出让所有进程执行完的序列即为安全态。
- **当前口径**：安全性检测在一轮扫描中按进程号递增持续寻找可执行进程（找到后继续向后扫），
  一轮结束再从头开始。经典样例因此得到 `P1→P3→P4→P0→P2`；页面 C++/Python 示例原先
  每找到一个就从 P0 重扫，得到 `P1→P3→P0→P2→P4`，与动画不一致。
- **处理（已修复）**：把 os.js 里 C++/Python 示例改成“一轮不回退”，与生成器逐位一致；
  两者都是安全序列，但同一输入下示例与动画现在输出相同序列。
- 出处：汤小丹《计算机操作系统（第四版）》银行家算法；Silberschatz 同类样例。

## 4. 写者优先/读者写者、MVCC 等的教材差异

- 读者写者示例只演示“读者可并发、写者独占”的第一类（读者优先）基础规则，不实现
  写者优先的复杂变体；页面已注明。
- MVCC 可见性采用 PostgreSQL 风格快照：xid 严格有序，读者只看“先于自己开始且已提交”
  的版本（见下条修复）。

## 5. 非官方假设/可配置项（不把补全当官方）

- 页面置换的“编辑距离 1–2 归拼写、只用于归因不改判对错”、判断题缩写不接受、
  连字符按一个词计数等，是雅思模块的非官方假设（见 `docs/ielts/RULES.md`）。
- IEEE 754 尾数展示采用直接截取前 23 位（教学简化），原生 `DataView` 用就近舍入；
  生成器页面对此标注“截取”，不声称与硬件逐位一致（`13.625` 等可精确表示值两者一致）。
